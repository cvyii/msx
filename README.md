# Smart TV Launcher for Media Station X

Start parameter URL:

`https://cvyii.github.io/msx-smart-tv-launcher/start.json`

Direct menu URL:

`https://cvyii.github.io/msx-smart-tv-launcher/menu.json`

The MyTV tile currently opens the public IPTV directory at `https://iptv-org.github.io/` because no private portal or M3U URL was supplied. Replace the `action` value in `menu.json` if a private MyTV URL is available.
